
I would like you to implement a module named TopModule with the following
interface. All input and output ports are one bit unless otherwise
specified.

 - input  clk
 - input  reset
 - input  slowena
 - output q (4 bits)

The module should implement a decade down-counter that counts from 9 down to 0, inclusive, with a period of 10 (after 0 it wraps back to 9). The reset input is active high
synchronous, and should reset the counter to 9. We want to be able to
pause the counter rather than always decrementing every clock cycle, so
the "slowena" input if high indicates when the counter should decrement.
Assume all sequential logic is triggered on the positive edge of the
clock.
