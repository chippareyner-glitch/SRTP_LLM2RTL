
I would like you to implement a module named TopModule with the following
interface. All input and output ports are one bit unless otherwise
specified.

 - input  clk
 - input  reset
 - input  data
 - output start_shifting

The module should implement a finite-state machine that searches for the
sequence 1101 in an input bit stream. When the sequence is found, it should set start_shifting to 1 for exactly one clock cycle and then continue searching; overlapping occurrences count (e.g. 1101101 contains two occurrences). Reset is active
high synchronous. Assume all sequential logic is triggered on the
positive edge of the clock.
