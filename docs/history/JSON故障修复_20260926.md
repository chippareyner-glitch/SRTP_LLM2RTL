## 已完成修改

- pyslang通过Python读取UTF-8源码后使用fromText解析，解决实际OneDrive中文路径的原生文件读取问题。
- --check不再只检查文件是否存在，会在项目实际目录做一次pyslang分析、Icarus编译及VVP仿真。正式批次在第一个API请求前也执行该检查。
- 新JSON流程中每次逻辑API调用最多3次请求；对连接读取中断、临时网络故障、429和部分5xx做2/4秒退避；鉴权、余额等错误不盲重试。所有请求尝试和配置写入request_attempts.json。

- 连续3道题API失败后停止批次，并列出not_attempted题目；不再让大量题在同一故障下继续请求。
- 删除initial中的占位输入名示例，要求使用实际端口；要求驱动后等待稳定；对能够进入已知状态的无复位触发器先驱动/时钟后检查。
