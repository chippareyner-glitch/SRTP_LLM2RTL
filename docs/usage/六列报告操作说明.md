# DeepSeek V4 实验与六列报告

在本目录打开 PowerShell。API 从 `.env` 读取，模型由原有 `llm_client.py` 调用。不要把密钥写到命令中。

## 重新生成并测试全部题目

```powershell
.\run.ps1 experiment --all --dataset '..\testbench\testbench\verilog-eval-main\verilog-eval-main\dataset_spec-to-rtl' --max-repairs 4 --report '..\数据.xlsx'
```

此命令会调用 API，首次生成后最多反馈修复 4 次，即每题最多 5 轮。通过即停止。每次运行自动建立新的实验目录；若只要一次生成，将 `--max-repairs 4` 改为 `--max-repairs 0`。

流程：run_experiment.py → llm_client.py 调用 DeepSeek → code_eval.py 编译和仿真 → export_results.py 导出 Excel/CSV。Excel 由 Python 整理真实测试结果，测试成绩不由模型判断。

## 仅重新导出已有结果（不调用 API）

```powershell
.\run.ps1 experiment --all --dataset '..\testbench\testbench\verilog-eval-main\verilog-eval-main\dataset_spec-to-rtl' --max-repairs 0 --output '.\experiments\deepseek_full_20260920' --resume --report '..\数据.xlsx'
```

已有 156 题均已完成，以上命令直接导出。若其他实验未完成，`--resume` 会继续未完成题目；仅导出可直接用正常 Python 运行 `export_results.py --run 实验目录 --output 输出.xlsx`。

## 字段定义

- 题号：完整 case_id。
- 类别：沿用旧表“数据_备份_20260920.xlsx”的“大类”，存放于 case_categories.json；新增题目无映射时显示“未分类”。
- 迭代次数：该实验中实际启动的生成轮数，首次为 1，含 API 失败的轮次。独立补生成实验不并入首轮实验。
- 语法是否通过：沿用 code_eval 的 syntax_pass，即 DUT、参考模块及测试平台联合编译结果。
- 功能是否通过：沿用实际仿真结果；未进入仿真显示“未执行”，API 异常显示“未判定”。
- 报错原因：末轮编译/仿真日志或 API 错误，通过时为空。详细历史仍在每题 attempt_* 目录。

现有 deepseek_full_20260920 是每题一轮、零反馈修复的实验，共 156 题，131 题通过；其迭代次数均为 1，不能当作已经执行了多轮修复。

导出沿用 validator.py 的 openpyxl 技术路线，并按指定的六列调整。已有文件覆盖前自动备份；文件被 Excel 占用时另存带时间的新文件。Python 环境需安装 openpyxl（本机 run.ps1 使用的环境已具备）。
