**Key characteristics:**
- 32-bit parallel input/output
- Positive edge-triggered sequential logic
- Synchronous active-high reset
- Falling edge detection with latching behavior
- Independent detection per bit position

**Critical Design Decisions:**

2. **Timing:** Detect on current cycle, update output on next positive edge
3. **Priority:** Reset has highest priority, overrides any edge detection

**Implementation Strategy:**

- Generate detection using: `detect = prev_in & ~current_in`
- Set output using: `out <= reset ? 32'b0 : (out | detect);`
